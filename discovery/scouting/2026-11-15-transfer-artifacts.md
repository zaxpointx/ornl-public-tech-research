# Scout report: tech transfer, sponsor pages and artifact repositories, cybersecurity first (2026-11-15)

Scope: Scout D pass on 2026-11-15 for round 2, asking which public ORNL cybersecurity tools exist outside GitHub and outside ornl.gov news. I covered three surfaces that round 1 did not. (1) ORNL technology-transfer listings and the partner or startup pages they lead to. These were reached only from search results or from links shown on fetched pages: `ornl.gov/technology-transfer/` linked the Security and Defense category, which linked "View Full Portfolio" and a "View All" filter. Innovation Crossroads and licensee pages were included. (2) Sponsor and award pages: DOE CESER CEDS peer-review and fact-sheet pages, CyManII, DHS S&T Transition to Practice, CISA, DOT/NHTSA, DARPA and SBIR/STTR listings. (3) Artifact repositories: the Zenodo REST API (queries recorded below), IEEE DataPort, Sandia's RAIICE data catalog, OLCF's DOI service (doi.ccs.ornl.gov, reached from RAIICE and search), the OSTI dataset record, figshare/Mendeley/Kaggle by search, and USENIX/ACSAC/NDSS artifact pages by search. The bound was about 12 new candidates and about 40 fetches. I made about 43 fetches: 33 WebFetch, about 9 Zenodo API calls and 1 GitHub API call. Two of them returned 404, and three PDFs were read locally from the fetch cache. Every candidate was grepped by name and URL against `discovery/catalog.csv`, `discovery/leads.csv`, both `discovery/snapshots/*.json` and both round-1 scout reports. Round-1 queries were not repeated. No subdomains were enumerated and no ORNL paths were guessed. Every ornl.gov and doi.ccs.ornl.gov URL came from a search result or from a link on a fetched page. No datasets or code were downloaded. Licensing and fact-sheet pages show emails and phone numbers; none were recorded. Names appear only as public authorship or stated roles (RULES 22). Claims are tagged [KNOWN], [INFERRED] or [UNKNOWN], and all were accessed 2026-11-15.

## Top 3 for deeper study

1. **OAKBAT** (`oakbat`). This is the strongest new artifact. It is a public, DOI-registered ORNL dataset of real RF spoofing and interference recordings, with scenario files and equipment configs on GitHub. It is deliberately parameter-matched to TEXBAT, which makes a clean experiment possible: does a spoofing detector's verdict change when only the recording hardware changes? A builder would learn GNSS spoofing signatures (power, correlation-peak distortion, clock jumps) and how equipment confounds a security benchmark. That is the same lesson the ROAD lab taught for CAN. Depth: data plus configs; no ORNL analysis code. Caveats: about 77 GB per series, Globus access, and the download needs the owner's OK. A metadata-only study of the GitHub repo is possible first.
2. **MSU/ORNL power-system attack datasets** (`msu-ornl-power-system-attack-datasets`). These are small, downloadable and widely reused grid-IDS benchmarks whose classes force a model to separate cyber attacks from natural faults and operator actions. That is the central hard problem in grid-attack detection, and it links to `ai-phyx`, `grid-digital-twin` and Cyber Grid Guard. Depth: data you can run locally today. A builder learns whether reported accuracies survive leakage-aware splits; the UAH page itself warns of shortcut patterns in a sibling set. Attribution needs a referee ruling, because ORNL is a named contributing lab, not the owner.
3. **RF private-cell audit** (`rf-private-cell-audit`), with CYVET as runner-up. It has the most buildable mechanism among the listing-only finds: passive baseline-and-deviation monitoring of cellular broadcast identifiers with commodity SDRs and open-source tools. A builder can study the detection logic from the listing and public open-source analogues without touching any network. Depth: listing only, so this is an artifact-study lead. CYVET is the better documented sponsor project (fact sheet plus deck, $3.4M, ORNL-led), but it has no code, and its Energy-Star-style rating method is described only at a high level.

Scope notes: no offensive capability was studied. The driver-identification dataset contains human-subject biometrics under no-re-identification terms. The MDA STTR trail was stopped at the abstract.
