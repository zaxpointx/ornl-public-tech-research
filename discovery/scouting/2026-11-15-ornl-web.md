# Scout report: ORNL web surfaces, cybersecurity then software engineering (2026-11-15)

Scope: one ornl-scout pass on 2026-11-15 for the question "what public ORNL cybersecurity and software-engineering projects exist outside the GitHub software catalog and the two 2026-11-11 snapshots, and which have enough public material to study?" Surfaces covered were web search (`site:ornl.gov` plus topic words, and "Oak Ridge National Laboratory" plus cyber/software terms), ornl.gov news, research highlights, publication pages, the CAISER center page, ORNL project pages reached through search results, ORNL technology-listing references shown on news pages, R&D 100 coverage, and attribution checks on non-ORNL hosts (Zenodo, arXiv, GitHub, CRAN, one OSTI record to confirm attribution). The bound was about 15 new candidates and about 40 fetches; 38 fetches were used, several of which returned 404 or redirected to the ORNL homepage (logged below). Every candidate was grepped against `discovery/catalog.csv`, `discovery/leads.csv` and both snapshots by name and URL before recording. Skipped as already present: Hyperion, Situ, Heartbeat, Akatosh, CAN-D, Cyberwheel, TASQC, Stucco (DOE CODE snapshot, `stucco-archive/morph` and OSTI code 72963), Nessus Visualization and other `ornl-sava` repos, PRESTO (`ORNL/PRESTO`, DOE CODE 156362), ELDSentry, CANRate, the Moriano CAN masquerade benchmarks, Data Driven User Emulator, OLCF Test Harness. No subdomains were enumerated and no URL paths were guessed; every ornl.gov page fetched came from a search result or a link shown on a fetched page. No personal emails or phone numbers were recorded, although several pages display licensing-contact emails.

## Top 3 for deeper study

1. **ROAD CAN intrusion dataset** (`road-can-dataset`). This is the only cyber candidate here with a public, licensed, downloadable artifact large enough to run against: real-vehicle captures with labeled attacks, in candump and signal-translated form. It pairs with the cataloged CAN-D signal reverse-engineering work and with the Moriano masquerade benchmarks already in the DOE CODE snapshot, so a builder could reproduce a published CAN IDS baseline end to end and measure where it fails. It supports experiment depth, and the main things to learn are labeling discipline for attack data and why signal-level detection beats ID/timing detection for masquerade attacks.
2. **UnifyFS** (`unifyfs`). Mature public code with CI, a peer-reviewed design paper, and an unusual mechanism: a job-lifetime file system built from I/O interception plus a "lamination" consistency model that relaxes POSIX until a file is declared final. It supports code reconstruction and a small local experiment (single-node build and an N-1 write test). It is squarely in the linux-infra lane. One caveat is attribution: the repo is LLNL's and ORNL rests on OSTI 1995690, so the coordinator should decide whether it belongs in the catalog or the connections map under RULES 13.
3. **Photon** (`photon`). It is the strongest ai-agents mechanism found: decentralized attack agents that share findings and adapt, built by turning a hyperparameter-search engine into an adversarial search engine and scaled to Frontier. ORNL's code is not public, so this supports artifact study only, but DeepHyper is public. A builder could rebuild the inversion pattern on a small local model, kept separate from any claim about ORNL's implementation. It teaches decentralized versus manager-agent orchestration and treating red-teaming as an optimization problem.

Close runner-up: Cyber Grid Guard, whose blockchain-backed configuration-integrity mechanism is clearly described but has no code (artifact study only).

Scope notes: AMIGO's purpose is generating evasive malware. Study it at the level of its published description and evaluation role only; do not reconstruct malware generation. The CAISER page frames work around national-security domains (biometrics, geospatial intelligence, nonproliferation) that were not pursued. Range and testbed candidates are paper and description studies only; nothing about their hosts or networks was looked up. No trail led toward restricted or classified material.
