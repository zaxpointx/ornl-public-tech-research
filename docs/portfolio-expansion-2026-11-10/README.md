## What crosses the domains

These are questions for comparison, not newly asserted dependencies:

- Can a downstream scientific conclusion remain trustworthy if the stream silently drops an input? Compare streaming policy with the SNS pipeline's reduction and cataloging responsibilities.
- Does a model's apparent success measure the outcome we actually want? Compare enzyme selectivity with conversion yield, solver convergence with residual verification, and simulation output with measured microstructure.
- What assumptions survive into a final decision? Compare weather time/unit conventions, uncertain building attributes, and molecular/image descriptors.
- Which work can be repeated from public artifacts, and which still requires unavailable data or institutional infrastructure? Keep conceptual local reconstructions separate from reproducing a published result.

Read the individual chapters for documented connections and exact limitations before using any of these comparisons as an engineering proposal. Human review remains necessary for scientific interpretations. No upstream packages, experiments, facility interfaces, or real-world systems were run in this research batch.
