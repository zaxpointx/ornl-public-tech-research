# Security and responsible reporting

This repository contains public-source research and documentation. It is not an operational ORNL system and does not authorize scanning, probing, or access to restricted infrastructure.

If you find credentials, private information, restricted material, or a claim that could create a safety or privacy risk, do not open a public issue with the details. Contact the maintainer privately through the GitHub profile and provide only the minimum information needed to locate the problem. Remove secrets from any local copy and do not attempt to validate access.

For ordinary factual corrections, use the public correction issue template.
