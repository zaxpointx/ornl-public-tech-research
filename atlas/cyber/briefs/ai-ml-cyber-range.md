## Walkthrough (plain language)
- **What it is:** A test range ORNL built to compare AI/ML-based security products under controlled, repeatable conditions. [KNOWN: 1]
- **The problem:** Vendors say their AI catches threats; buyers need a fair, repeatable test. [KNOWN: 1]
- **What goes in:** Security tools under test, malware samples and network attack scenarios. [KNOWN: 1]
- **What happens:** Two national government challenges: endpoint tools against 100K malware samples, and network detection of break-in attempts of varying stealth inside a busy business network. [KNOWN: 1]
- **What comes out:** Performance and operating-cost comparisons. [KNOWN: 1]
- **Where humans act:** Range staff design scenarios and remove easy giveaways the tools could key on. [KNOWN: 1]
- **What it is not:** Not a public range. [INFERRED]
- **Example:** Every endpoint product faces the same malware set, run the same automated way. [KNOWN: 1]
- **Unknown:** Which agencies ran the challenges. The AMIGO story names a Navy challenge; a tie to this range is INFERRED.
