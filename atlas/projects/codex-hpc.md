# Codex for HPC Kernel Generation

**Area:** AI-assisted scientific computing

## Public evidence
- [ORNL publication: Evaluation of OpenAI Codex for HPC parallel programming models kernel generation](https://www.ornl.gov/publication/evaluation-openai-codex-hpc-parallel-programming-models-kernel-generation)

## Why it is unusual
This is a direct bridge between coding agents and high-performance scientific software, not generic autocomplete.

## Local experiment
Benchmark Codex-generated implementations against hand-written baselines, require tests and performance measurements, and record failure modes.

**Boundary:** Do not assume current Codex behavior equals the 2023 evaluation.
