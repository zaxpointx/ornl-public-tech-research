## Research contract

Investigate Flowcept, Zambeze, DataFed, and the INTERSECT SDK as public software artifacts. The purpose is to help readers and local Codex/Hermes workflows understand execution, provenance, messaging, and scientific-data boundaries well enough to design reproducible software experiments. Compare their responsibilities without assuming that all four constitute a deployed ORNL stack.

Public primary pages, reports, public repository files and documentation only. No credentials, facility access, external changes, upstream code execution, or changes to Hermes. Existing dossiers and the October reconstruction remain preserved. Private implementation, complete institutional deployment, operational ownership, and undocumented interoperability remain UNKNOWN.
